# Nextflix

A modern movie discovery web application built with **Next.js** that allows users to search movies, explore trending films, and view detailed movie information.

## Features

* Search movies by title
* Browse trending and popular movies
* View detailed movie information
* Ratings, release date, overview, and genres
* Fully responsive design
* Fast performance with Next.js
* Clean, modern UI

---

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Shadcn UI
* OMDb API

## Installation

1. Clone the repository:

```bash
git clone https://github.com/anurag-dwivedi-live/nextflix.git
````

2. Navigate to the project folder:

```bash
cd nextflix
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file from the example file:

```bash
cp .env.example .env
```

> On Windows (Command Prompt):

```bash
copy .env.example .env
```

5. Add your API keys and environment variables to `.env`.

6. Run the development server:

```bash
npm run dev
```

7. Open in your browser:

```text
http://localhost:3000
```
